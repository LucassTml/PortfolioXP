Audian

RustDitado por voz offline

Ditado por voz para Windows, open-source e inspirado no Wispr Flow. O reconhecimento de fala (Whisper ou Parakeet) e um LLM pequeno (Qwen) rodam no próprio computador, sem internet, e transformam o que você fala em texto bem escrito em qualquer programa.

CódigoBaixar

OpenlyAntigravity

JavaScriptPlugin para o OpenCode

Plugin para o OpenCode que usa o seu próprio Antigravity (agy) no terminal como agente. Assim dá pra aproveitar o plano do Google que você já paga, sem chave de API paga e sem OAuth.

Código

GenAI Text-to-SQL

PythonPerguntas viram SQL

Agente que transforma perguntas em português em consultas SQL sobre a camada Gold do CineData, no Databricks. Tem guardrails, busca semântica, troca de modelo pelo OpenRouter e interface em Streamlit.

Como usar

  • Dê dois cliques em um ícone da área de trabalho para abrir. No celular, um toque basta.
  • Arraste as janelas pela barra de título. Dois cliques na barra maximizam.
  • O botão iniciar tem todos os programas, inclusive os jogos em Todos os programas.
  • Passe o mouse sobre os ícones para ver o que cada um faz.

Atalhos de teclado

Ctrl + K ou /Abre o Executar
EscFecha menus
F2Novo jogo (nos jogos)
↑ ↓ e TabHistórico e autocompletar no Prompt de Comando

Mudar a aparência

Clique com o botão direito na área de trabalho e escolha Propriedades. Lá dá para trocar o esquema de cores (azul, verde-oliva ou prateado), o papel de parede, a proteção de tela e até passar para o visual do Vista.
